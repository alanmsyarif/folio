# Folio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser editor that turns a PDF into page images, lets you draw image / video / video-link / link boxes on pages, and exports a static page-flipping viewer folder.

**Architecture:** No build step. `shared/` holds two classic scripts (`model.js` pure logic, `overlays.js` DOM for one page's overlays) that load unchanged in the editor, the exported viewer and `node --test`. The editor is an ES module served by a stdlib node server (pdf.js needs http for its worker). The exported viewer is classic scripts plus `book.js` (`window.BOOK = …`) so it also runs from `file://`.

**Tech Stack:** Vanilla JS/HTML/CSS, pdfjs-dist 6.4.299 (`vendor/pdf.min.mjs`, `vendor/pdf.worker.min.mjs`), page-flip 2.0.7 (`vendor/page-flip.browser.js`, global `St.PageFlip`, MIT), File System Access API, Node 24 `node:test`.

**Spec:** `docs/superpowers/specs/2026-10-13-folio-design.md`

## Global Constraints

- Editor targets Chromium (Opera GX); viewer must work in any modern browser, from `file://` and from a static host.
- No bundler, no framework, no runtime npm dependencies; vendored files are committed.
- Overlay geometry `x y w h` is fractions 0–1 of the page.
- Page images: WebP, long side 2000 px, quality 0.85.
- Link `href` schemes allowed: `http:`, `https:`, `mailto:` only; external links open in a new tab with `rel="noopener noreferrer"`.
- Embeds: YouTube → `https://www.youtube-nocookie.com/embed/ID`, Vimeo → `https://player.vimeo.com/video/ID`.
- Media files are named `media/<overlay id>.<ext>`; pages `pages/<n>.webp`.
- Export writes `index.html viewer.css viewer.js model.js overlays.js overlays.css page-flip.browser.js book.js pages/ media/`.

## Review Focus

1. **Exporting into a folder that isn't a Folio book** (say, Documents with its own `media/` subfolder): expected to ask before writing and never delete files there. Pinned by the `staleFiles` "foreign folder" test in Task 1 and the confirm in Task 5.
2. **Re-exporting into the same folder the book was opened from:** expected to work repeatedly. Files read from that folder go stale once rewritten, so `openBook` copies them into memory. Pinned by the manual check in Task 6 (export twice, reopen, export again).
3. **Real-world video URLs** (`&t=30s`, `&list=`, `m.youtube.com`, `youtu.be/…?si=`, Shorts, unlisted Vimeo `vimeo.com/ID/HASH`): expected to embed; anything else is rejected with a message. Pinned by the `toEmbedUrl` tests in Task 1.
4. **Hand-edited or hostile `book.js`** (`src: "../../x"`, `href: "javascript:…"`, page image outside `pages/`): expected to be ignored or refused, never to read or write outside the book folder or run script. Pinned by the `usedPaths`, `isSafeHref` and `parseBookJs` tests in Task 1 and the safe-href guard in `overlays.js` (Task 2).
5. **Password-protected or corrupt PDF:** expected to show "Could not open PDF: …" and leave the editor usable. Pinned by the manual check in Task 3.

```js
// Static server for the editor (pdf.js needs http:// for its worker). Usage: node serve.js [port]
const http = require('http');
const fs = require('fs');
const path = require('path');

const root = __dirname;
const port = Number(process.argv[2]) || 8080;
const types = {
  '.html': 'text/html; charset=utf-8', '.js': 'text/javascript', '.mjs': 'text/javascript',
  '.css': 'text/css', '.json': 'application/json', '.svg': 'image/svg+xml',
  '.webp': 'image/webp', '.png': 'image/png', '.jpg': 'image/jpeg', '.mp4': 'video/mp4',
};

http.createServer((req, res) => {
  const rel = decodeURIComponent(new URL(req.url, 'http://x').pathname);
  if (rel === '/') { res.writeHead(302, { Location: '/editor/' }).end(); return; }
  const file = path.join(root, rel.endsWith('/') ? rel + 'index.html' : rel);
  if (!file.startsWith(root + path.sep)) { res.writeHead(403).end(); return; }
  fs.readFile(file, (err, data) => {
    if (err) { res.writeHead(404).end('Not found'); return; }
    res.writeHead(200, { 'Content-Type': types[path.extname(file)] || 'application/octet-stream' }).end(data);
  });
}).listen(port, '127.0.0.1', () => console.log(`Folio editor: http://127.0.0.1:${port}/editor/`));
```

```js
// Folio book model: pure helpers shared by the editor, the exported viewer and node tests.
// Classic script: sets globalThis.FolioModel; under node also module.exports.
(function (root) {
  'use strict';

  const TYPES = ['image', 'video', 'embed', 'link'];
  const MIN_SIZE = 0.02; // smallest box side, as a fraction of the page, so boxes stay clickable

  // Template files copied into every export: [path in repo, name in export folder].
  const VIEWER_FILES = [
    ['viewer/index.html', 'index.html'],
    ['viewer/viewer.css', 'viewer.css'],
    ['viewer/viewer.js', 'viewer.js'],
    ['shared/model.js', 'model.js'],
    ['shared/overlays.js', 'overlays.js'],
    ['shared/overlays.css', 'overlays.css'],
    ['vendor/page-flip.browser.js', 'page-flip.browser.js'],
  ];

  function toEmbedUrl(url) {
    let u;
    try { u = new URL(url); } catch { return null; }
    if (u.protocol !== 'https:' && u.protocol !== 'http:') return null;
    const host = u.hostname.replace(/^(www|m)\./, '');
    if (host === 'youtube.com' || host === 'youtube-nocookie.com' || host === 'youtu.be') {
      const id = host === 'youtu.be'
        ? (u.pathname.match(/^\/([\w-]+)/) || [])[1]
        : u.pathname === '/watch'
          ? u.searchParams.get('v')
          : (u.pathname.match(/^\/(?:shorts|embed|live)\/([\w-]+)/) || [])[1];
      return id && /^[\w-]{11}$/.test(id) ? 'https://www.youtube-nocookie.com/embed/' + id : null;
    }
    if (host === 'vimeo.com' || host === 'player.vimeo.com') {
      const m = u.pathname.match(/^\/(?:video\/)?(\d+)(?:\/([\da-f]+))?\/?$/);
      if (!m) return null;
      const hash = m[2] || u.searchParams.get('h');
      return 'https://player.vimeo.com/video/' + m[1] + (hash && /^[\da-f]+$/.test(hash) ? '?h=' + hash : '');
    }
    return null;
  }

  function isSafeHref(href) {
    try { return ['http:', 'https:', 'mailto:'].includes(new URL(href).protocol); } catch { return false; }
  }

  function clampRect(r) {
    const w = Math.min(1, Math.max(MIN_SIZE, r.w));
    const h = Math.min(1, Math.max(MIN_SIZE, r.h));
    return {
      x: Math.min(1 - w, Math.max(0, r.x)),
      y: Math.min(1 - h, Math.max(0, r.y)),
      w, h,
    };
  }

  function validateOverlay(o, pageCount) {
    if (!TYPES.includes(o.type)) return 'Choose a type';
    if (o.type === 'image' || o.type === 'video') return o.src ? null : 'Pick a file';
    if (o.type === 'embed') return toEmbedUrl(o.url || '') ? null : 'Not a YouTube or Vimeo link';
    const hasHref = typeof o.href === 'string' && o.href !== '';
    const hasPage = o.page !== undefined && o.page !== null;
    if (hasHref === hasPage) return 'Set a web address or a page number';
    if (hasHref) return isSafeHref(o.href) ? null : 'Address must start with http://, https:// or mailto:';
    return Number.isInteger(o.page) && o.page >= 1 && o.page <= pageCount ? null : 'Page must be 1–' + pageCount;
  }

  function firstInvalid(book) {
    for (let page = 0; page < book.pages.length; page++) {
      for (const o of book.pages[page].overlays) {
        const error = validateOverlay(o, book.pages.length);
        if (error) return { page, id: o.id, error };
      }
    }
    return null;
  }

  function newId() {
    return 'o' + Math.random().toString(36).slice(2).padEnd(8, '0').slice(0, 8);
  }

  function mediaName(id, fileName) {
    const ext = (fileName.match(/\.([a-z0-9]{1,5})$/i) || [null, 'bin'])[1].toLowerCase();
    return 'media/' + id + '.' + ext;
  }

  function isLocalPath(p) {
    return typeof p === 'string' && /^(pages|media)\/[^/\\]+$/.test(p) && !p.includes('..');
  }

  function usedPaths(book) {
    const used = new Set();
    for (const page of book.pages) {
      if (isLocalPath(page.image)) used.add(page.image);
      for (const o of page.overlays) if (isLocalPath(o.src)) used.add(o.src);
    }
    return used;
  }

  // Files in pages/ or media/ that the book no longer uses. Only deletes inside a folder that
  // already held a book.js, so exporting into an unrelated folder never removes its files.
  function staleFiles(book, folder, names, rootNames) {
    if (!rootNames.includes('book.js')) return [];
    const used = usedPaths(book);
    return names.filter(n => !used.has(folder + '/' + n));
  }

  function serializeBook(book) {
    return 'window.BOOK = ' + JSON.stringify(book, null, 1) + ';\n';
  }

  function parseBookJs(text) {
    const m = text.match(/^\s*window\.BOOK\s*=\s*([\s\S]*?)\s*;?\s*$/);
    if (!m) throw new Error('Not a Folio book.js');
    let book;
    try { book = JSON.parse(m[1]); } catch { throw new Error('Not a Folio book.js'); }
    if (!book || book.version !== 1 || !Array.isArray(book.pages)) throw new Error('Unsupported book.js version');
    for (const p of book.pages) {
      if (!/^pages\/[^/\\]+$/.test(p.image || '') || p.image.includes('..')) throw new Error('Bad page image path: ' + p.image);
      if (!Array.isArray(p.overlays)) p.overlays = [];
    }
    return book;
  }

  const api = {
    VIEWER_FILES, toEmbedUrl, isSafeHref, clampRect, validateOverlay, firstInvalid,
    newId, mediaName, isLocalPath, usedPaths, staleFiles, serializeBook, parseBookJs,
  };
  root.FolioModel = api;
  if (typeof module === 'object' && module.exports) module.exports = api;
})(globalThis);
```

```js
// Builds the DOM for one page's overlays. Shared by the editor preview and the exported viewer.
// srcFor maps a stored path ("media/o1.png") to a URL: the viewer passes paths through,
// the editor returns blob URLs.
(function (root) {
  'use strict';
  const M = root.FolioModel;

  function renderOverlay(o, srcFor) {
    let el;
    if (o.type === 'image') {
      el = document.createElement('img');
      el.src = srcFor(o.src);
      el.alt = '';
      el.draggable = false;
    } else if (o.type === 'video') {
      el = document.createElement('video');
      el.src = srcFor(o.src);
      el.controls = true;
      el.playsInline = true;
      el.preload = 'metadata';
    } else if (o.type === 'embed') {
      el = document.createElement('iframe');
      el.src = M.toEmbedUrl(o.url) || 'about:blank';
      el.allow = 'autoplay; fullscreen; picture-in-picture; encrypted-media';
      el.allowFullscreen = true;
      el.referrerPolicy = 'strict-origin-when-cross-origin';
      el.title = 'Video';
    } else {
      el = document.createElement('a');
      if (o.page) {
        el.href = '#page=' + o.page;
```

```js
// Renders every PDF page to a WebP blob with pdf.js.
import * as pdfjs from '../vendor/pdf.min.mjs';

pdfjs.GlobalWorkerOptions.workerSrc = new URL('../vendor/pdf.worker.min.mjs', import.meta.url).href;

// Long side of each baked page, px, and WebP quality. Bigger = sharper zoom, heavier export.
const LONG_SIDE = 2000;
const QUALITY = 0.85;

export async function pdfToPages(file, onProgress) {
  const pdf = await pdfjs.getDocument({ data: new Uint8Array(await file.arrayBuffer()) }).promise;
  try {
    const blobs = [];
    let width = 0, height = 0;
    for (let n = 1; n <= pdf.numPages; n++) {
      const page = await pdf.getPage(n);
      const base = page.getViewport({ scale: 1 });
      const viewport = page.getViewport({ scale: LONG_SIDE / Math.max(base.width, base.height) });
      const canvas = document.createElement('canvas');
      canvas.width = Math.round(viewport.width);
      canvas.height = Math.round(viewport.height);
      await page.render({ canvasContext: canvas.getContext('2d'), viewport }).promise;
      if (n === 1) { width = canvas.width; height = canvas.height; }
      blobs.push(await new Promise((ok, fail) =>
        canvas.toBlob(b => (b ? ok(b) : fail(new Error('WebP encoding failed on page ' + n))), 'image/webp', QUALITY)));
      page.cleanup();
      onProgress(n, pdf.numPages);
    }
    return { blobs, width, height };
  } finally {
    await pdf.destroy();
  }
}
```

```js
function urlFor(path) {
  if (!state.blobs.has(path)) return path;
  if (!state.urls.has(path)) state.urls.set(path, URL.createObjectURL(state.blobs.get(path)));
  return state.urls.get(path);
}

function setBlob(path, blob) {
  if (state.urls.has(path)) {
    URL.revokeObjectURL(state.urls.get(path));
    state.urls.delete(path);
  }
  state.blobs.set(path, blob);
}

  $('status').textContent = text;

  state.dirty = true;
  renderLayer();
  renderProps();
}
```

```js
  if (o.type === 'image' || o.type === 'video') {
    const file = input('p-file', 'file', { accept: o.type === 'image' ? 'image/*' : 'video/mp4,video/webm' });
    file.onchange = async () => {
      const f = file.files[0];
      if (!f) return;
      const path = M.mediaName(o.id, f.name);
      // Copy into memory so the box survives the source file being moved or rewritten.
      setBlob(path, new Blob([await f.arrayBuffer()], { type: f.type }));
      o.src = path;
      changed();
    };
    props.append(...field(o.type === 'image' ? 'Image file' : 'Video file (MP4 or WebM)', file));
    if (o.src) {
      const cur = document.createElement('p');
      cur.className = 'hint';
      cur.textContent = 'Current: ' + o.src;
      props.append(cur);
    }
  } else if (o.type === 'embed') {
    const url = input('p-url', 'url', { placeholder: 'https://www.youtube.com/watch?v=…', value: o.url || '' });
    url.onchange = () => { o.url = url.value.trim(); changed(); };
    props.append(...field('Video address', url));
  } else if (o.type === 'link') {
    const href = input('p-href', 'url', { placeholder: 'https://…', value: o.href || '' });
    href.onchange = () => {
      const v = href.value.trim();
      if (v) { o.href = v; delete o.page; } else delete o.href;
      changed();
    };
    const pg = input('p-page', 'number', { min: 1, max: state.book.pages.length, value: o.page ?? '' });
    pg.onchange = () => {
      const n = parseInt(pg.value, 10);
      if (Number.isNaN(n)) delete o.page; else { o.page = n; delete o.href; }
      changed();
    };
    props.append(...field('Web address', href), ...field('…or go to page', pg));
  }

  const error = M.validateOverlay(o, state.book.pages.length);
  if (error) {
    const p = document.createElement('p');
    p.className = 'error';
    p.textContent = error;
    props.append(p);
  }

  const del = document.createElement('button');
  del.type = 'button';
  del.textContent = 'Delete box';
  del.onclick = deleteSelected;
  props.append(del);
}

function deleteSelected() {
  page().overlays = page().overlays.filter(o => o.id !== state.selected);
  state.selected = null;
  changed();
}
```

```js
    if (mode === 'move') r = { ...orig, x: orig.x + dx, y: orig.y + dy };
    else if (mode === 'draw') r = { x: Math.min(start.x, p.x), y: Math.min(start.y, p.y), w: Math.abs(dx), h: Math.abs(dy) };
    else {

      if (handle.includes('n')) { r.y += dy; r.h -= dy; } else r.h += dy;
    }
    Object.assign(o, M.clampRect(r));
    state.dirty = true;
    renderLayer();
  };
  const onUp = ev => {
    layer.removeEventListener('pointermove', onMove);
    layer.removeEventListener('pointerup', onUp);
    layer.removeEventListener('pointercancel', onUp);
```

```js
// Reads and writes an exported book folder with the File System Access API (Chromium only).
const M = window.FolioModel;

async function writeFile(dir, name, data) {
  const w = await (await dir.getFileHandle(name, { create: true })).createWritable();
  await w.write(data);
  await w.close();
}

async function entryNames(dir, kind) {
  const names = [];
  for await (const [name, handle] of dir.entries()) if (!kind || handle.kind === kind) names.push(name);
  return names;
}

async function readBlob(root, path) {
  const [folder, name] = path.split('/');
  const file = await (await (await root.getDirectoryHandle(folder)).getFileHandle(name)).getFile();
  // Copy into memory: a File read from this folder goes stale once Export rewrites it.
  return new Blob([await file.arrayBuffer()], { type: file.type });
}

export async function exportBook(book, blobs) {
  // Fetch the viewer template before touching the folder, so a failure writes nothing.
  const template = await Promise.all(M.VIEWER_FILES.map(async ([from, to]) => {
    const res = await fetch('../' + from);
    if (!res.ok) throw new Error('Viewer file missing: ' + from);
    return [to, await res.blob()];
  }));

  const root = await window.showDirectoryPicker({ id: 'folio', mode: 'readwrite' });
  const rootNames = await entryNames(root);
  if (rootNames.length && !rootNames.includes('book.js') &&
      !confirm(`"${root.name}" already has files and isn't a Folio book. Write the book into it anyway? Nothing there will be deleted.`)) {
    return null;
  }

  for (const [to, blob] of template) await writeFile(root, to, blob);
  for (const path of M.usedPaths(book)) {
    const [folder, name] = path.split('/');
    await writeFile(await root.getDirectoryHandle(folder, { create: true }), name, blobs.get(path));
  }
  for (const folder of ['pages', 'media']) {
    const dir = await root.getDirectoryHandle(folder, { create: true });
    for (const name of M.staleFiles(book, folder, await entryNames(dir, 'file'), rootNames)) await dir.removeEntry(name);
  }
  // Written last: a folder only counts as a book once everything it points to is there.
  await writeFile(root, 'book.js', M.serializeBook(book));
  return root.name;
}

export async function openBook() {
  const root = await window.showDirectoryPicker({ id: 'folio', mode: 'read' });
  let text;
  try {
    text = await (await (await root.getFileHandle('book.js')).getFile()).text();
  } catch {
    throw new Error(`No book.js in "${root.name}". Pick a folder made by Export.`);
  }
  const book = M.parseBookJs(text);
  const blobs = new Map();
  for (const path of M.usedPaths(book)) {
    try {
      blobs.set(path, await readBlob(root, path));
    } catch {
      throw new Error(`"${root.name}" is missing ${path}`);
    }
  }
  return { book, blobs };
}
```

````markdown
# Folio

Turn a PDF into a page-flipping book with images, videos and links on any page, and export it as a

YouTube embeds usually refuse to play from a file opened on disk. They work once the folder is hosted
````
